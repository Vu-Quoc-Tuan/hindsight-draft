# NocPro Chain Explain Web

React 19 + TypeScript operator workspace for the FastAPI adapter. Vite proxies
`/api` to `http://127.0.0.1:8000` in development.

```bash
pnpm install
pnpm dev
```

Verification:

```bash
pnpm test
pnpm lint
pnpm build
```

The browser only renders API projections. Membership, channel, derivation,
audit and evolution semantics remain in the Python analysis services.
